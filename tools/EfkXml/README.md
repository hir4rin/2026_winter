# EfkXml: Effekseer の .efkefc をエディタなしで書き換える

Effekseer のエディタは1つしか動かせず、ほかのセッションと取り合いになる。そこで、.efkefc の中身をテキストの XML に出して、スクリプトで書き換えて戻すためのツールを作った。
書き出し(.efk)はエディタでしかできないので、エディタを使うのは「開く → 書き出す」の数秒だけで済む。

## .efkefc の中身(調べた結果)
- 先頭は `EFKE` と版(4バイト)。そのあとにチャンクが並ぶ: 4文字のID + 大きさ(int32) + 中身。
  - `INFO`: 使っているテクスチャなどの一覧。エディタで保存し直すと作り直される。
  - `EDIT`: zlib(`78 9C`)で圧縮した**バイナリの XML**。
- バイナリの XML:
  - 要素名の表: 数(u16)、それぞれ 長さ(u16)・文字列・番号(u16)。
  - 値の表: 要素名の表と同じ形。
  - 木: 一番上の要素の数(u16)。要素ごとに 名前の番号(u16)・値があるか(u32)。
    - 値があるとき: 値の番号(u32)・0(u16)。
    - 値がないとき: u32 が1なら子の数(u16)と子が続く。0なら空の要素。
- 中身の形は MCP の `node_xml_get` の `<CopiedNode>` と同じ(`Node` / `Name` / `CommonValues` …)。

## 使い方
```powershell
# 取り出す(XML は UTF-8)
.\Efk.ps1 get 元.efkefc 出力.xml
# 戻す(efkefc の EDIT だけ入れ替える。INFO はそのまま)
.\Efk.ps1 set 書き換える.efkefc 入力.xml
# ノードの一覧と値をざっと見る
.\Summary.ps1 入力.xml
# 確認用のノード(Debug / MarkFront / MarkRight / DebugDummy)を消した書き出し用のコピーを作る
.\MakeExport.ps1 入力.xml 元.efkefc 出力.efkefc
```
- `Lib.ps1` に書き換え用の関数がある(`Get-N` ノードを名前で探す、`Set-V` 値を入れる(無い要素は作る)、`Set-R` 乱数の Center/Min/Max、`Set-Ring` / `Set-RingCol`、`Copy-N` ノードの複製、`Import-N` 別のファイルからノードを持ってくる)。
  使い方の例は `../../EffectTools/ChargeAttack/edit_AC_v2.ps1`。
- 書き換えたファイルはエディタで開けることを確かめてある(12ファイルとも 取り出す → 戻す → 取り出す で同じになる)。
- テクスチャを新しく使ったときは INFO が古いままになるが、エディタで開いて保存すれば直る。書き出し(.efk)は問題なかった。
- 書き出し用のコピーは、元と同じフォルダに置く(テクスチャのパスがファイルからの相対のため)。
