## 作り方のメモ
- エフェクトの +Z = ゲームでの前(`PlayerStateSkillAttack::UpdateGhostEffect` と同じ向きで出す想定)。分身のモデルは頭が -Z 向きなので Y を180°回す
- 分身のモデルは体の長さが約12。斬り抜けの距離は30、敵は Z=15・高さ12 の想定
- 動く親(LocationFCurve)の子に、毎フレーム `WhenCreating` で分身・リボンを置くと通り道に残る
- リボンは「視点に向ける(ViewpointDependent)」をオンにすると描かれなかった。オフにして横向きと縦向き(Z 90°)の2本にした
- モデル・テクスチャのパスは作業フォルダの中のコピーを指す(`data/Effect/Skill/` に書き出したときに同じ並びになる)
- `DebugEnemy` は確認用。書き出すときは消す
