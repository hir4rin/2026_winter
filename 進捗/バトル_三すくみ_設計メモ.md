# バトルの三すくみ 設計メモ(ガードブレイク・スキル弱/強・溜め・アーマー)

2026-11-24 に会話で決めた方向。**まだ実装していない**。数値・細かい仕様は未定(最後の「決めること」)。

---

## 1. なぜ変えるか

- ガードブレイクが「打ち上げ専用」になっている。打ち上げは普段のコンボ(X→Y など)でも出したい。
- 結局どの場面でも「弱 → 強」で済んでしまう。プレイヤーの選択がない。
- 原作(NG4)のように「スキル攻撃でガード・アーマーを破る」にしたいが、今のスキルは1種類で、出すと必ず打ち上げる。

---

## 2. 今の関係(コードから)

| 事実 | 場所 |
|---|---|
| 敵がガードするのは**地上で弱攻撃を受けたときだけ**(確率 `guardRate`) | `EnemyBase::OnDamage` |
| 被弾後は弱攻撃が `forceHitCount`(3)回まで必ず当たる | `EnemyBase::OnDamage` |
| 後隙(AttackEnd)・ガードブレイク中はガードしない | `EnemyBase::OnDamage` |
| ガード中に**強攻撃 → すぐガードブレイク** | `EnemyGuard::OnGuardHit` |
| ガード中に弱攻撃 → ゲージがたまり、満タンで**弾き**(プレイヤーがひるむ → 敵の反撃) | `EnemyGuard::OnGuardHit` |
| ガード中に**スキル・必殺技 → 割れずにそのままダメージ** | `EnemyBase::OnDamage` |
| ボス(R0・Kingmech)は攻撃の流れの間は怯まない(実質アーマー) | 各ボスの `OnDamage` |
| ガードブレイク → チャンス(スロー0.2) → Y で打ち上げ(GuardBreakAttack0/1) | `PlayerStateGuardBreakChance` / `PlayerStateGuardBreakAttack` |

```
弱   ──勝つ──> 無防備な敵・予備動作中の敵
ガード ──勝つ──> 弱(当て続けると弾かれる)
強   ──勝つ──> ガード(すぐ割れる)
強   ──勝つ──> 無防備な敵
回避 ──勝つ──> 敵の攻撃
ボスの攻撃 ──勝つ──> こちらの攻撃全部(怯まない)
```

### 問題点
1. **強攻撃に負ける相手がいない**。ガードにも無防備にも勝つ → 「弱 → 強」に集まる。
2. 「弱3回が通る → ガードされる → 強で割る」の順番が、作りそのもので弱→強を教えている。
3. **Y の連打はガードされない**(ガードは弱攻撃のときだけ)。強攻撃だけで押し切れる。
4. スキルはガードを素通りするので、ガードに対しては「スキルを撃つ」か「強で割る」になり、ゲージを払う理由が薄い。

## 3. 変更の方向

| 項目 | 今 | 変更後 |
|---|---|---|
| 打ち上げ | ガードブレイクのご褒美(チャンス中に Y) | **普段のコンボで出す**(X→Y など) |
| 強攻撃(短押し) | ガードをすぐ割る | **ガードを割れない**(防がれる) |
| ガードの発生 | 弱攻撃のときだけ | **弱・強の両方**(Y 連打の穴をふさぐ) |
| 溜め強(長押し) | 無い | **通常の技として追加**。弱→強の単調さを崩す。アーマーを潰せる。ガードは割れない |
| スキル | 1種類・必ず打ち上げ | **スキル弱 / スキル強に分ける** |
| スキル弱(ゲージ小) | ― | **ガードを割る** → 割れたら Y で**山場の一撃**(専用の技) |
| スキル強(ゲージ大) | ― | 今のスキル(打ち上げ)。**アーマーを潰す**。ガードには素通りのダメージだけ(割れない・山場の一撃なし) |
| 敵のアーマー攻撃 | ボスの攻撃中のみ(実質) | **雑魚にもアーマー付きの攻撃を足す** |
| 弾き | 弱攻撃でゲージがたまったら | そのまま(弱連打への罰) |

### ガードブレイクの山場の一撃
- 今の `PlayerStateGuardBreakChance` と `GuardBreakChanceUI`(Y・リング)はそのまま使い、**Y で出す中身を打ち上げ → 強力な一撃に替える**。
- 候補: 部位を斬る(Kingmech のガトリングのように) → 確殺につなぐ。
- 演出の候補(前に出した案): ヒットストップ、短いスロー、よろめきの姿勢、敵にひび(残り時間を表す)、最初の一撃を重く。

### 決めたこと・やめたこと
- やめた: アーマー破壊とガードブレイクを同じ「崩れ」状態にする → 全部「弱 → 強」でよくなり、選択がなくなる。
- やめた: 溜め攻撃でガードブレイク → 渋い。溜めは「弱→強の単調さを崩す通常の技」としてだけ入れる。
- 決めた: ガードブレイクの後には強力な専用の一撃を出す。

## 4. 変更後の関係

| こちら＼敵 | 無防備 | ガード | アーマーの攻撃 | 普通の攻撃 |
|---|---|---|---|---|
| 弱 | ○ | ×(弾かれる) | ×(止まらない) | ○(予備動作中なら止める) |
| 強(短押し) | ○(X→Y で打ち上げ) | ×(防がれる) | × | △(遅いので当たり負け) |
| 溜め強 | ○ 重い一撃 | ×(防がれる) | **○ 潰す**(溜める間に殴られる危険) | × 溜める間に殴られる |
| スキル弱(ゲージ小) | ○ | **○ 割る → Y で山場の一撃** | ×(止まらない) | ○ |
| スキル強(ゲージ大) | ○ 打ち上げ | △ 素通りでダメージ(割れない) | **○ 潰す** | ○ |
| 回避 | ― | ― | ○(ジャスト回避なら反撃) | ○ |

```
通常攻撃(弱・強) ──> 無防備な敵 ──(ゲージがたまる)
ガード          ──> 通常攻撃
スキル弱        ──> ガード  …ゲージ小、割れたら山場の一撃
アーマーの攻撃   ──> 通常攻撃・スキル弱
溜め強 / スキル強 ──> アーマー
   溜め強: 時間のリスクを払う / スキル強: ゲージを払う
回避            ──> 敵の攻撃全部
```

### これで変わること
- **どの行動にも負ける相手がいる** → 一択がなくなる。
- **資源の流れ**: 通常攻撃でゲージをためて、スキルで崩す。「いつ・どちらに使うか」が判断になる。
- **同じ答えでも払うものが違う**: アーマーには時間(溜め)かゲージ(スキル強)。ガードにはスキル弱が一番得(山場の一撃が付く)。
- 打ち上げは普段の X→Y、崩しは別の手段 → 「弱→強」が何でもこなす状態ではなくなる。

---

## 5. 残る穴・決めること

1. **スキル強が強すぎないか**: ガードにもダメージが通り、アーマーも潰す → ゲージが余るとこれだけになりやすい。出の遅さ・消費量で調整。
2. **ゲージのたまり方**: 少ないとガードの固い敵が退屈、多いとスキル一択。ガードされた攻撃でも少したまる、など。
3. **溜めのリスクは集団戦でしか効かない**: 1対1のアーマー持ち(ボス)には溜めが安全な答えになりやすい。ボスの攻撃間隔、溜め中に割り込む技で調整。
4. **ガードを強攻撃にも発生させるか**: Y 連打の穴を塞ぐには必要。そのかわり敵がガードする場面が増える。
5. スキル弱・強の入力(案: LB+X / LB+Y)。
6. 山場の一撃の中身(部位を斬る・確殺につなぐ・普通の敵とボスで変えるか)。
7. 溜め強の入力・溜め時間・コンボのどこから出せるか。
