## 流れ(30fps)

| 時間 | コマ | 動き |
|---|---|---|
| 8.75〜8.85 | 約3F | 沈む。低く構えて刀を後ろの下へ |
| 8.85〜8.95 | 約3F | 刃先で床を擦って火花(予告) |
| 8.95〜9.30 | 約10F | 横回転で約2回転しながら背丈の2倍ほど上がる。敵とくっついたまま。1回転5〜6F |
| 9.30〜9.60 | 約9F | 頂点で回転を止め、刀を広げて敵と並んで浮く → 空中コンボへ |

## 片手剣にするとき

- 2回転のまま。周ごとに刀の高さを変えて弧をずらす(1周目は腰で水平、2周目は肩で斜め上)
- 左手を回転と逆に振って体の軸の勢いを出す
- 刃を床に付けて後ろへ引く溜め＋火花で、今の切り上げ(`Attack_Up_Floor_To_Air_02`)と見分ける
- 最後は刀を振り抜いたまま止める
- CSV: 判定を回転ごとに2〜3つ(`;` 区切り)、moveSpeedY は今の切り上げ(40)より上、最後のヒットだけヒットストップ長め
