## 分かったこと

### 1. 普通の走り・回避にはほぼエフェクトが無い
- 07_ground_dodge.jpg: 回避・低い姿勢の走りでも、光や煙はほとんど出ない。出ても足元に小さい火花が数粒(刀か足の擦れ)。
- 速さはアニメ(低い前傾姿勢)と、マフラー/腰布の黒い帯がなびくことで見せている。
- → 常に出るエフェクトを足すと「軽さ」が消える。出すなら「始まり」と「着地」の一瞬だけ。

### 2. 速さの一瞬は「白い半透明の風の筋」
- 03/04: 落下中に腕を広げる瞬間、体を包むように白い筋が放射状・らせん状に出る。
  - 色: 白〜うすい青灰。透明度高め(背景が透ける)。加算というより半透明の重ね。
  - 形: 細い曲線の筋がたくさん。体を中心に外へ広がり、ねじれている。塊(煙の玉)ではない。
  - 時間: 動画で約0.07秒(4F前後)で最大 → 0.4〜0.5秒でちぎれた細い筋が数本残って消える。
- 05: 空中投げで回転しながら落ちるときも同じ白い筋が体にらせんで巻き付き、着地で平たく広がる。
- → ヤクモの「動きのエフェクト」の共通の言語は **白い風の筋**。赤は使っていない。

### 3. 赤は鵺(血鴉)の型と攻撃だけ
- 08: 鵺の型の発動は赤いリング + 血の破片 + 刀に沿った赤い筋。派手で重い。
- レールも滑った後が赤く光る(01, 02)が、これはレール側の演出。
- → 普段の移動に赤を使うと攻撃・血の演出とぶつかる。移動は白、攻撃は赤と分けている。

### 4. レール滑り・踏み切りは火花
- 01: 足元からピンク〜紫の小さい火花が後ろへ流れる。
- 02 (36.1秒): レールから跳ぶ瞬間、足元からオレンジの火花が散る(一瞬)。

### 5. 参考: 敵の高速移動は「青い残像」
- 06: 白い敵が瞬間移動するとき、体の形の青い半透明の残像が4〜5体並び、筋でつながる。0.3秒ほどで消える。
- ヤクモ自身の演出ではないが、「ダッシュの残像」を作るなら参考になる。

## うちのゲームに持ってくるなら(案)
| 場面 | 案 | 長さ |
|---|---|---|
| ダッシュ(FastRun)の入り | 体を包む白い風の筋が後ろへ広がる(03の小さい版)。透明度 0.3〜0.5 | 0.3秒 |
| ダッシュ中 | 何も出さない or 体の横に細い風の線を数本だけ(たまに) | 常時(軽く) |
| ジャンプの踏み切り | 足元に平たい白い風の輪 + ちぎれた筋数本 | 0.2〜0.3秒 |
| 二段ジャンプ | 足の下に白い風の輪(踏み切りより少し大きい) | 0.3秒 |
| 着地 | 平たい風の輪を地面に(05の着地の小さい版) | 0.2秒 |

- 素材: 細い曲線の筋のテクスチャ(端で alpha 0)を自作する。柔らかい煙(付属の texture_generate)だと塊に見えてヤクモらしくない。
- 色は白〜うすい青。赤は攻撃・血のエフェクトに取っておく。

## 追記: ジャンプの白いもや(ユーザーの録画 2026-11-19 153129.mp4 の 35.1〜35.6 秒)
- 画像: `rec_jump/crop_3510_full.png`(1フレームずつ)・`rec_jump/crop_3440.png`・`rec_jump/crop_2130.png`
- 宙返りのジャンプで、**両足の通り道に白い半透明の細い筋が尾を引く**(足に追従する軌跡。刀の軌跡=ソードトレイルの足版)。
  - 踏み切りの瞬間: 地面から足へ、もやっとした太めの白い流れ。
  - 回っている間: 細い筋が数本、足の弧に沿ってカーブする。中は透けている。
  - 尾の長さは足の動きの0.2〜0.3秒ぶんくらい。古い側から消える。
- 普通の走りでは出ていない(この録画の範囲)。
