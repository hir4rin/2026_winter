# 「忍」 設定とセリフ（案 v1）

NINJA GAIDEN 4 の「近未来の都市 × 忍者 × 妖」の空気を参考にしたオリジナルの設定。
名前・組織・用語はすべて原作と被らないようにしている。
今ゲームにあるもの（列車ステージ、サイバーステージ、兵士3種、海賊のボス→四本腕に変身、キングメック、暗殺、血殺、赤い刀、ランク）に合わせてある。

---

## 1. 世界観

### 舞台：常夜（とこよ）の街・新東京
- 2070年代。十年前の「夜蝕（やしょく）事件」で、東京の上に巨大な結界が張られ、空が明けなくなった。
- 結界の中では、昔から人の影に潜んでいた **妖（あやかし）** が実体を持つようになった。
- 街はネオンと広告で光り続けている。昼が来ないので、街の明かりが太陽の代わり。

### 敵：九頭（くず）重工
- 結界の中の治安を「請け負っている」民間軍事企業。実質、新東京の支配者。
- 妖を狩り、その血 **「妖血（ようけつ）」** を絞って、兵器の燃料や兵士の強化に使っている。
- 夜蝕事件そのものが、九頭が妖血を手に入れるために起こしたもの（＝物語の核心）。

| ゲームの敵 | 設定 |
|---|---|
| Swordman | 九頭の「刃兵（じんぺい）」。高周波ブレードを持つ一般兵 |
| Gunner | 「銃兵」。遠くから撃ってくる |
| Bazooka | 「砲兵」。ロケット弾。重装備で動きは遅い |
| 海賊のボス（第1ラウンド） | 傭兵団「黒潮（くろしお）」の頭目 **バルザ**。九頭に雇われた海賊あがりの剣士 |
| 海賊のボス（変身後） | 妖血を自分に打ち込み、背中から妖の腕が2本生えた姿。「四ツ腕のバルザ」 |
| キングメック | 九頭の拠点防衛用 大型機兵 **〈KINGMECH〉**。妖血を燃料に動く。背中からミサイルの雨 |

### 主人公の力
- **刀**：普段の刀。
- **血殺（けっさつ）**：倒した敵の妖血を刀が吸い、溜まると解放できる一族の秘術。
  刀が赤く染まり（＝赤い刀）、世界が血の色に沈む（＝赤いフォグの演出）。
- **暗殺**：気づかれる前に背後・空中から一撃で仕留める。忍の本分。

## 2. キャラクター

### 主人公：忍（シノブ）
- 妖を斬ることを生業にしてきた忍の一族 **「朧衆（おぼろしゅう）」** の最後の生き残り。
  一族は夜蝕事件の夜、九頭に滅ぼされた。「忍」は名前ではなく、一族で最後に残った者が名乗るコードネーム。
- 年齢 20代半ば。寡黙。必要なことしか言わない。
- 感情を表に出さないが、仲間を見捨てない。ナビのリコにだけは、たまに少しだけ柔らかい。
- 口調：短い。語尾を伸ばさない。「〜だ」「〜か」「問題ない」「行く」。敬語は使わない。一人称「俺」。
- 目的：九頭重工の中枢へ辿り着き、結界を壊して夜を明けさせること（表向き）。一族の仇（本音）。

### ナビゲーター：天音（あまね）リコ
- 結界の外から通信で忍を支援するオペレーター。18歳。ハッカー。
  小型ドローン「ツクモ」を飛ばして敵の位置を調べる（＝ロックオンやマップ・扉の情報の言い訳になる）。
- はきはき・元気・テンポが速い。数字や作戦をきっちり言う。忍の無口に毎回ツッコむ。
- 夜蝕事件で家族が結界の中に取り残されている。だから「夜を明けさせる」ことに本気。
- 口調：「〜だよ！」「〜して！」「了解っ」「ちょっと、聞いてる？」。忍のことは「シノブ」と呼ぶ。一人称「わたし」。

### 二人の関係
- リコがしゃべって、忍がひとことで返す、がいつもの形。
- リコは忍を心配しているが、照れ隠しで事務的にふるまう。忍はそれに気づいている。
- 物語が進むと、忍の返事が少しだけ長くなる（＝信頼の表現）。

## 4. セリフ

## 5. 決めたいこと（次に相談）

1. 主人公の名前は「忍（シノブ）」でいいか、別の名前にしてコードネームを「忍」にするか
2. ナビの名前「天音リコ」でいいか
3. セリフを出す方法：画面の下に字幕＋顔アイコン（通信ウィンドウ）にするか、字幕だけか
4. ゲームに入れるなら CSV にする（例：`id, 話す人, 文, 表示時間`）。フェーズのイベント（BossAppear など）から呼ぶ
5. 声（ボイス）を付けるか。付けない場合は、通信の「ピッ」という音と文字送りの音だけでも雰囲気は出る
