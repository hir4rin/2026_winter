# 液体の血の勉強(2026-11-26)

必殺技の溜めで血を吸い込むエフェクト(`data/Effect/Blood/UltBloodAbsorb`)を「液体の血」にするために調べたこと。

## NINJA GAIDEN 4 の録画から(`Videos/画面録画/画面録画 2026-10-07 135639.mp4`)

ヤクモの血殺の発動(6.8秒・14.3秒あたり)と、床の血を集める忍術(21〜22秒あたり)。画像は `liquid_ref/`。

- **遠くから一直線に飛んでくる流れは無い**。血は体のまわり(体の高さの1〜1.5倍の半径)を**円を描いて回る**。
- 液体は「管」ではなく**幅の広い三日月の帯**。何本もの帯が向きを変えて重なり、球の表面をなぞるように回る(`ng4_swirl_6.95s.png`)。
  - 帯の中に、流れる向きの**細い筋**がある。先(頭)は太く明るく、尾は細くなって消える。
  - 色は明るい赤〜ピンクで、少し光っている(半透明＋加算っぽい)。
- 帯と一緒に、**暗い赤の平らな破片**と細かいしぶきが飛ぶ(つやのない欠片。前に勉強した NG4 の血と同じ)。
- 床の血は、**床の上を回りながら縮む弧**になって中心へ集まる(`ng4_floor_21.95s.png`)。
- 中心(体)には赤いもやと光。

## VFX の作り方として調べたこと

- 液体の流れは「帯(リボン・メッシュ)＋流れる向きの筋のテクスチャ＋柔らかいふち」で作るのが普通。
- 尾を崩すときは、部分ごとの寿命で少しずつ削る。ふちが鋭すぎると「破れた紙」、崩しすぎると「紙吹雪」に見える。
- 参考: [80.lv 血しぶきの4つの作り方](https://80.lv/articles/four-methods-for-creating-blood-splatter-effect-explained)、[realtimevfx の血の作り込み](https://realtimevfx.com/t/im-working-on-some-blood-stuff/496)、[realtimevfx 魔法の爆発の渦メッシュ](https://realtimevfx.com/t/magic-explosion-spell-breakdown/19039)

## 試してだめだったもの(このエフェクトで)

| 作り方 | 見え方 |
|---|---|
| Track の線・移動方向の破片を遠くから集める | 「赤い線にしか見えない」(ユーザー) |
| Track を太く(20倍で頭 0.65) | ピンクの半透明の管・触手 |
| Track に AlphaCutoff で尾を崩す | 点線の細い線 |
| 滴を `WhenCreating_FollowParent` で頭に遅れてついてこさせる | 流れにとげが生えた |
| 中くらいの Track ＋落ちる滴 | 液体らしいが、遠くから伸びる線に見える所が残る |

## 今の作り(三日月の帯で渦を巻く)

- Effekseer の **Ring の Crescent**(始まりと終わりの角度を Easing にして「走る弧」)に、液体の帯の画像を貼る。半径を Easing で縮めて中心へ吸い込む。
- 帯の画像 `UBA_LiquidArc_a / UBA_LiquidArc2_a`(`gen_liquid_arc.ps1`): U が弧に沿う向き(尾0→頭1)。頭は太く丸く、尾は細く滴に崩れる。中に流れる向きの筋、中心の少し上につやの線。白ベースで色はノードで付ける。
- 帯を2枚重ねる: 普通の合成の深い赤(`SwirlBand`)と、少し広い加算の赤(`SwirlGlow`、光って見える)。
- 帯の親(`Swirl`)の向きをランダムにして、球をなぞるように回す。床には横に寝かせた帯(`FloorSwirl`)。暗い破片(`Shard`、BH_Shred_c)と滴(`AbsorbFine`)も一緒に集める。
