## 作り直しの方針(10/31 夜。それまでの版は「ずれてきた」ので捨てた)

- **デモステージ・列車ステージが遊びやすかった理由をまねる**: 真っすぐな一本道(+Z)、道の中心がずれない、区画の役割がはっきり、
  移動のギミックは区画のつなぎ目だけ(看板1枚の壁走り・3m幅の縦穴・一方通行の飛び降り)、1エリアの敵は2〜4体
- **Excel の Ch1 間取り図の区画を順番どおりに**つなぐ。大きさは Excel を少しつめたもの。寄り道(1-11 配給担当官・1-17 煉獄の門・1-18 ゴーディ)と、Excel に無い場所(地下鉄・下の通り)は入れない
- 道の中心は x=0(スタート〜広場)と x=6(広場から先)の2つだけ。全長約600m(Excel どおりなので長め)
- 単位は m(Unity の 1m = ゲームの 100)。スタートの床が y=0。原点の上8m以内に物を置かない

## NINJA GAIDEN 4 Ch1 の作りから学んだこと

参考: [GameRant の Ch1 攻略](https://gamerant.com/ninja-gaiden-4-chapter-one-guide-all-collectibles-location-ng4/)、[Hardcore Gamer のサイドミッション](https://hardcoregamer.com/ninja-gaiden-4-mission-guide-chapter-1-bloodsoaked-tokyo/)

- 一本道。**移動(壁走り・壁蹴り)が戦闘と戦闘の間をつなぐ**。「縦穴を壁蹴りで登る → 壁走りが2連続 → 社の端末 → ピラミッド前の戦闘 → パイロン」
- 壁走りは「**崩れた道**」(道が途切れて、横の壁だけが続いている所)を渡るのに使う
- 後半はワイヤーと壁走りで溝をいくつも越えてから、ボスへ
- 壁走りできる壁の目印の決まりは資料に無かった → このステージでは**壁走りできる壁は全部同じ見た目**(黒い看板＋太い水色の枠＋進む向きの矢印＞)。溝の縁は黄色く光る線

## ギミックの決まり(ゲームの数値から)

- 壁走り 8/F、時間制限なし。キックは進行方向+壁の法線の 45° に 20/F＋上に 10/F。普通のジャンプは初速 18/F・重力 1/F²(最高 約1.6m)
- **壁走りの溝は8m**。壁は溝の手前・向こうへ4mずつ伸ばす。**溝のまわりは壁の横の5mだけ通れる**(反対側は `NarrowBlock` でふさぐ。上の縁に赤い線)
- 溝の底は4m下。**落ちたら斜面で溝の手前に戻るだけ**(ゲームに落下で復帰する仕組みが無いため)。まわり道はできない → 壁走りしないと先に進めない
- **壁蹴りの縦穴は壁の間2.5m・奥行き8m**(`ShaftHalfWidth`)
- 飛び降りは一方通行(戻れなくてよい)

## 見た目の決まり(10/31 夜)

- **デバッグっぽい光る線は使わない**(ヘリポートの H・床の線・枠など)。光る物はアセットの看板・窓・ネオン柱だけ。例外は壁走りの看板(水色の枠と矢印)
- 溝の縁は黄色く塗ったコンクリートの縁(`GapEdge`)、溝のまわりのふさぎはレンガの建物のかたまり＋上の縁石(`NarrowBlock`)
- 広い車道(`Street` でアスファルト・幅10m以上)は建物側に歩道(幅2m・15cm高い)と縁石、真ん中にマンホール。細い道・広場は床の格子
- 建物の列で埋まらない所は、建物の形の箱(壁の材質・高さを変え、屋上の縁と1階の帯)で埋める(`FillerBuilding`)。奥の壁はレンガ
- 看板は壁から突き出す袖看板(`BladeSign`、アセットの高層ビル用看板を2倍、表と裏の2枚)。広場・ぬれた通り・看板の通り・工業区画
- **色(書き出しで調整)**: 本体の色は夜の色(×0.68/0.70/0.80)、床はさらに×0.75。窓・看板の明かり(発光マップ)はテクスチャに焼き込む(×1.1)。
  前は発光を材質全体にかけていて、建物が白っぽく平らになっていた。値は CyberStageTool.cs の `NightBase` / `FloorDarken` / `EmissionGain`
- ゲーム側: `StageInfo::useNightFog`(ステージ1だけ true)で、ステージに暗い青のフォグ(1500〜9000、色 10,12,24。Stage.cpp 先頭)

## Unity での作り方・直し方

Unity プロジェクト: `C:\Users\tsyts\Desktop\programm\ninja_motion`(Unity 2022.3.62f3、Built-in)
ツール: `Assets/Editor/CyberStageTool.cs`(メニュー `Tools > Cyber Stage`)。素材は `Assets/Cyberpunk_Megapolis`

- `1. Build Stage1 (Create Scene)`: 上の表どおりに `Assets/Scenes/CyberStage1Scene.unity` を作り直す(**シーンでの調整は消える**)。
  区画は `BuildStartAlley` などの関数に分かれている。導線を大きく変えるならここの数字を直して作り直す

  壁ゾーン `CyberStage_WallZones` → `WallZones/Stage005.csv`、エリア `CyberStage_PhaseAreas` → `PhaseAreas/Stage005.csv`、敵 `EnemySpawns` → `Enemies/Enemies005.csv`。

  はみ出す建物は置かない(別の区画に食い込まないように)。建物は道の床と同じ高さに建てる

- 溝の長さは8mのまま。ダッシュジャンプ(ダッシュ 18/F・ジャンプ初速 18/F・重力 1/F² で滞空約36F)で約6.5m跳べるので、それより短いと壁走りしなくても越えられる。
