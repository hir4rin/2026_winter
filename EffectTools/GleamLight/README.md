# 地上弱スキル(LB＋X)のエフェクト

忍者外伝4 リュウの閃華の弱(調査は `../RyuGleamLightRef/README.md`)をもとに、今のスキルの分身(`data/Effect/Skill/GhostDash`)を土台にして作る。

## 版
| 版 | フォルダ | 中身 |
|---|---|---|
| v1 | `GleamLight1_v1/` | 1段目の形。ほどけ→分身が一直線に斬り抜け→風の帯→赤い直線→白い残像 |
| v2 | `GleamLight1_v2/` | 連鎖を「敵を中心に6方向から2Fおきに斬り抜ける」に変更。色違い `GleamLight1_A_Ink`(赤黒)・`GleamLight1_B_Cutout`(白い切り絵)。比較は `captures/compare_v2_taste.png` |
| v3 | `GleamLight1_v3/` | **B に決定**。赤い直線をすべて消した |

## 弱2・弱3(1段目の v3 をコピーして作った。見た目は同じ白い切り絵・白青の風の帯・赤い線なし)
| 段 | フォルダ | 中身 |
|---|---|---|
| 弱2 v1 | `GleamLight2_v1/` | 分身2体が左右(X=±11)から X 字に交差して斬り抜け(8F) → 敵を中心に10回・1Fおきの連鎖 → 敵の中心から白いギザギザの筋が放射状に弾ける(20F、`GL_Streak.png`・`tools/gen_streak.ps1`) → 両側の抜けた先に白い残像 |
| 弱3 v1 | `GleamLight3_v1/` | 敵の真上(Y=34)へ跳ぶ(8F) → 頭を下にして止まる → 真下へ突き下ろす(17〜21F) → 3本の風の帯が回りながら敵を巻いて降りる → 21Fに着地: 地面の輪(`ShockRing.png`)・白い破片(`GB_Shard.png`)・放射状の筋・着地の姿勢(`Ghost_AirSlam_Impact`)の白い残像 |
- 段が進むほど派手にした(弱1: 連鎖6回 → 弱2: 交差＋連鎖10回＋筋 → 弱3: 跳び上がり・突き下ろし・渦・着地の衝撃)。
- どれも敵は Z=15 の想定で、エフェクトの +Z をプレイヤーの前にして足元から出す。

## 保持リスト(ユーザーが良いと言ったもの。直すときに壊さない)
- 空中スキルとはテンポ感が違う連鎖(直線の斬り抜けが星形に重なる。2Fおき・6回)
- B の白い切り絵の分身(光らない白・縁の光なし・白く細い溶けの縁取り)

## やめたもの
- 赤い直線(v3 で削除。ユーザーの指示)

## 作り方のメモ
- エフェクトの +Z = ゲームでの前(`PlayerStateSkillAttack::UpdateGhostEffect` と同じ向きで出す想定)。分身のモデルは頭が -Z 向きなので Y を180°回す
- 分身のモデルは体の長さが約12。斬り抜けの距離は30、敵は Z=15・高さ12 の想定
- 動く親(LocationFCurve)の子に、毎フレーム `WhenCreating` で分身・リボンを置くと通り道に残る
- リボンは「視点に向ける(ViewpointDependent)」をオンにすると描かれなかった。オフにして横向きと縦向き(Z 90°)の2本にした
- モデル・テクスチャのパスは作業フォルダの中のコピーを指す(`data/Effect/Skill/` に書き出したときに同じ並びになる)
- `DebugEnemy` は確認用。書き出すときは消す
