## NINJA GAIDEN 4 Ch1 の作りから学んだこと

参考: [GameRant の Ch1 攻略](https://gamerant.com/ninja-gaiden-4-chapter-one-guide-all-collectibles-location-ng4/)、[Hardcore Gamer のサイドミッション](https://hardcoregamer.com/ninja-gaiden-4-mission-guide-chapter-1-bloodsoaked-tokyo/)

- 一本道。**移動(壁走り・壁蹴り)が戦闘と戦闘の間をつなぐ**。「縦穴を壁蹴りで登る → 壁走りが2連続 → 社の端末 → ピラミッド前の戦闘 → パイロン」
- 壁走りは「**崩れた道**」(道が途切れて、横の壁だけが続いている所)を渡るのに使う
- 後半はワイヤーと壁走りで溝をいくつも越えてから、ボスへ
- 壁走りできる壁の目印の決まりは資料に無かった → このステージでは**壁走りできる壁は全部同じ見た目**(黒い看板＋太い水色の枠＋進む向きの矢印＞)。溝の縁は黄色く光る線

## ギミックの決まり(ゲームの数値から)

- 壁走り 8/F、時間制限なし。キックは進行方向+壁の法線の 45° に 20/F＋上に 10/F。普通のジャンプは初速 18/F・重力 1/F²(最高 約1.6m)
- **壁走りの溝は8m**。壁は溝の手前・向こうへ4mずつ伸ばす。**溝のまわりは壁の横の5mだけ通れる**(反対側は `NarrowBlock` でふさぐ。上の縁に赤い線)
- 溝の底は4m下。**落ちたら斜面で溝の手前に戻るだけ**(ゲームに落下で復帰する仕組みが無いため)。まわり道はできない → 壁走りしないと先に進めない
- **壁蹴りの縦穴は壁の間2.5m・奥行き8m**(`ShaftHalfWidth`)
- 飛び降りは一方通行(戻れなくてよい)

## 見た目の決まり(10/31 夜)

- **デバッグっぽい光る線は使わない**(ヘリポートの H・床の線・枠など)。光る物はアセットの看板・窓・ネオン柱だけ。例外は壁走りの看板(水色の枠と矢印)
- 溝の縁は黄色く塗ったコンクリートの縁(`GapEdge`)、溝のまわりのふさぎはレンガの建物のかたまり＋上の縁石(`NarrowBlock`)
- 広い車道(`Street` でアスファルト・幅10m以上)は建物側に歩道(幅2m・15cm高い)と縁石、真ん中にマンホール。細い道・広場は床の格子
- 建物の列で埋まらない所は、建物の形の箱(壁の材質・高さを変え、屋上の縁と1階の帯)で埋める(`FillerBuilding`)。奥の壁はレンガ
- 看板は壁から突き出す袖看板(`BladeSign`、アセットの高層ビル用看板を2倍、表と裏の2枚)。広場・ぬれた通り・看板の通り・工業区画
- **色(11/06。書き出しで調整)**: 区画ごとに色を変える。スタートの青 → 広場の青紫 → ぬれた通りの紺 → 妖魔の暗い赤 → 看板の通りの赤紫 → 倉庫・溝の黄土色と赤さび → 工業の黄緑 → 部屋の橙 → ボス前の赤、とだんだん熱くする。
  値は CyberStageTool.cs の `Zones`(壁・車道・歩道・床のコンクリート)と `SectionZones`(区画→色)。床は `FloorKind` で材質ごとに濃淡を強め、タイルは彩度を落とす。シーンの材質は変えない(Unity の見た目には出ない)。
  窓・看板の明かり(発光マップ)はテクスチャに焼き込む(×1.1)。
- `convert.exe night`: 拡散0.4・環境0.5。前の flat(0.1/0.9)は面の向きで明るさが変わらず、床と壁が同じ明るさで平らに見えていた
- ゲーム側: `StageInfo::useNightFog`(ステージ1だけ true)で、ステージに地平線の色のフォグ(2200〜4950、色 48,24,62。Stage.cpp 先頭)。カメラのファークリップ(5000)の手前で消しきる
- **空**: `StageInfo::skyDir` = `data/Stage/CyberStage/Sky`。`CyberStagePolish.GenerateSky` が作った絵(夜空・街明かりの雲・遠くのビル街)を `SkyBox` で描く。遠くの超高層ビルの区画(99_Background)はこれに置き換えて消した
- **導線の明かり(11/01)**: 色の意味をそろえる。暖色(オレンジ)＝進む方向・出口、水色＝壁走りの入口(看板の枠と同じ色)、黄色＝溝の縁、赤＝戦う場所。明かりは「電球＋床の光のたまり(半透明の板)」を mv1 に入れ、点光源の位置・色・届く距離は `data/Stage/Lights/Stage005.csv` に書き出す(ゲームでは `StageLights` がプレイヤーに近い8灯を明かり用のシェーダー `Render/Shader/StageLightPS.hlsl` に渡し、ステージ・キャラに光を加算で足す)。今あるのは 広場→縦穴(誘導灯3・縦穴の壁の明かり・上の通りの柱の明かり)、**壁蹴りの縦穴3か所すべてにオレンジの明かり2つずつ**(左の壁の中ほど・右の壁の上の方。`AddShaftLights`)、**進むルートの街灯29本**(11/01 見直し: 電球の箱は無し、腕が道の外を向いた4本は削除(スタートの最初の1本は内向きに置き直し)、**戦う場所(広場・ぬれた通りの門・看板の通り・工業・黄黒・閉じた部屋・鉄格子の着地点・ボス広場)の街灯は淡い白・弱め(Dim)**、進む道だけ暖色。アセットの CP_Street_Lamp_02 ＋ 頭に明かり。道の端から0.6m内側に約12mおきに左右交互、腕は道の内側へ。壁走りの通路・屋内・コンテナの谷には無し。`StreetLamp` / `AddStreetLamps`、パレットの「街灯(明かり付き)」)、連続壁走りの入口3つ(水色)、ボス広場の入口(柱2本)と社④の誘導灯。光のたまりはゲームで材質の色＋発光が足されるので、発光は色の半分にしている(全部だと黄色っぽくなる)

## 仕上げ(11/06、`Assets/Editor/CyberStagePolish.cs`)

シーンは作り直さず、保存済みのシーンに足して消した。**`ApplyAll` は適用済みなので2回呼ばない**(前のシーンは `ninja_motion/Backup/CyberStage1Scene_before_1106.unity`)。

- **歩ける所を当たり判定から求める**(`FloodWalkCells`): 1mごとに床を調べ、区画の種から広げる。`Analyze` は結果とずれを `Library/CyberStageAnalyze` に書く
- **隙間埋め**(`FindRuns` / `FillRun`): 当たり判定の壁より3.2m以上奥まで見た目が無い所を、窓・シャッターの部品を付けた建物の箱(`GapFill`)でふさぐ。85か所。手すりの所とボス広場の奥(ピラミッドを見せる)は対象外
- **落ちる穴**: 縦穴の上の足場の外側と、妖魔の部屋の扉の左右は何も無く落ちていたので見えない壁を足した(`FixHoles`)
- **小物**(`CyberStageDress`): 広場・ぬれた通り・看板の通り・倉庫・工業区画の壁ぎわに車・コンテナなど31個(当たり判定つき)。戦う場所の真ん中は空ける
- **敵**(`PlaceEnemies`): 3 → 4 → 5 → 6 → 7 → 8 → ボス。谷にはバズーカと、コンテナの上の銃を足した。phase は前と同じなので `PhaseStage005.csv` は変えていない
- **見えない面を省く**(`CyberStageVisibility`): 歩ける所の2mごと×高さ4段から6方向に描いて、映った三角形だけを書き出す。結果は `Assets/CyberStage/VisibilityBake.bytes`。1面も見えない物はシーンから消した
  - **シーンを直したら `Tools > Cyber Stage > 3. Bake Hidden Faces And Export`**(約2分)。`2. Export` だけでも動くが、動かした物・新しい物は全部の面が書き出される(穴は開かない)
  - 調べる高さは床から1.2〜9.5m。もっと高い所からカメラで見る演出を足すなら `Heights` を増やす
- テクスチャは壁・床・窓など `LargeTextures` だけ1024、ほかは512。書き出しで使わなくなったテクスチャは消す
