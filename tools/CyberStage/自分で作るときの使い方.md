# ステージを Unity で自分で作るときの使い方

Unity プロジェクト: `C:\Users\tsyts\Desktop\programm\ninja_motion`
ツール: `Assets/Editor/CyberStagePalette.cs`(部品パレット)と `Assets/Editor/CyberStageTool.cs`(書き出し・部品の中身)

## 1. はじめる

1. `Window > Cyber Stage Palette` でパレットを開く(最初は2台目のモニターに出ることがある。好きな所にドッキングしてよい)
2. 「表示・書き出し」タブの **空のシーンを作る**(スタートの床だけのシーン)。作ったら `Ctrl+S` で好きな名前で保存
   - 今のステージ1(`Assets/Scenes/CyberStage1Scene.unity`)を直して使ってもよい
3. シーンには5つのまとまりができる。**書き出されるのはこの中だけ**

| まとまり | 中身 | ゲームへ |
|---|---|---|
| `CyberStage` | 見た目。「区画」(子のまとまり)ごとに分ける | CyberStage.mv1 |
| `CyberStage_Collision` | 見た目に付いていない当たり判定(見えない壁など。半透明の緑の箱) | CyberStageCol.mv1 |
| 見た目の物の子の `〜_Col` | その物の当たり判定(緑の箱)。**見た目を動かす・回す・大きさを変えると一緒に付いてくる** | CyberStageCol.mv1 |
| `CyberStage_WallZones` | 壁走り(青)・壁蹴り(黄)のゾーン | WallZones/Stage005.csv |
| `CyberStage_PhaseAreas` | フェーズを進めるエリア(紫) | PhaseAreas/Stage005.csv |
| `EnemySpawns` | 敵 | Enemies/Enemies005.csv |

## 2. 置く場所の決め方(パレットの一番上)

- **置く位置 = Scene ビューの注視点**(画面の真ん中。物を選んで `F` キーで寄ると、そこが注視点になる)
- **置く高さ**: 置く物の底の高さ(m)。「選んだ物の高さ」で、選んでいる床の上面に合わせられる
- **位置のマス**: 注視点をこのマス目(初期 1m)にそろえる
- **向き**: 置く物の Y 回転(度)
- **置く区画**: `CyberStage` の下のまとまりの名前。▼で今ある区画から選べる。無い名前を書けば作られる

## 3. アセットを置く(「アセット」タブ)

- 分類: 建物(まるごと) / 建物の部品(壁・窓・シャッター) / 壁の飾り(看板・配管・室外機・電線) / 道路・歩道 / 小物 / 地下鉄 / 車 / 遠景
- **名前で探す**: 英語の名前の一部(例 `Vending`, `Fence`, `Signboard`, `Lamp`)。全分類から探す
- **クリック**: 注視点に置く(区画の中に入る。「当たり判定も作る」がオンなら外形の箱の当たり判定も作る)
- **ドラッグ**: Scene ビューの好きな所に置ける。ただし区画の外に置かれるので、置いた後「表示・書き出し」の **選んだ物を「置く区画」に入れる** を押す
- **右クリック**: お気に入り(★)に入れる / 外す。よく使う物は ★お気に入り の分類に集まる
- デカール(道路の白線など)はゲームに書き出せないので出していない

## 4. ゲーム用の部品(「ゲーム用の部品」タブ)

プレイヤーは +Z へ進む前提(壁走りの矢印・斜面・階段は +Z 向き)。置いた後に 90 度単位で回すのはよい。

| 部品 | 置き方 | 作られる物 |
|---|---|---|
| 床(箱) | 注視点が中心、上面が置く高さ | 見た目＋当たり判定 |
| 壁走りの壁(矢印の看板) | 注視点が壁の手前の端。左に立てる / 右に立てる | 黒い看板・水色の枠・矢印・支柱＋当たり判定＋**壁走りゾーン** |
| 壁蹴りの縦穴 | 注視点が底の真ん中 | 左右の壁・底の床＋当たり判定＋**壁蹴りゾーン**＋黄色い線 |
| 見えない壁 | 注視点が線の始まり | 当たり判定だけ(道の縁・まわり道をふさぐ) |
| 斜面 / 階段 | 注視点が下の端 | 見た目＋当たり判定(30度くらいまで) |
| 溝の縁 | 床の端に | 黄色い光る線 |
| コンテナ | 注視点が底の真ん中 | 6×2.6×2.4m の箱(上に乗れる) |
| ガラスのピラミッド | 注視点が底の真ん中 | 見た目＋3段の当たり判定 |
| 敵 | 足元 | 種類・フェーズ・グループ・初めの状態 |
| フェーズのエリア | 足元 | 名前は `PhaseStage005.csv` の EnterArea の param と同じに |

置いた物は `Ctrl+Z` で取り消せる。

### 壁走り・壁蹴りの寸法の目安

- 壁走りで渡る溝は **8m** くらい。壁は溝より前後に4mずつ長く、向こうの床は1mくらい低くすると乗りやすい
- 壁蹴りの縦穴は壁の間 **2.5m**、奥行き8m
- ゲームに落ちたら戻る仕組みが無いので、溝の底には床と、手前へ戻る斜面を置く。まわり道は見えない壁でふさぐ
- 壁走りできる壁は全部「矢印の看板」にして、ほかの所には使わない(分かりやすさのため)

## 5. 見やすくする・書き出す(「表示・書き出し」タブ)

- 当たり判定・壁ゾーン・エリアの **隠す / 見せる**(Scene ビューの表示だけ。書き出しには影響しない)
- **選んだ物に当たり判定を付ける**: アセットの物の外形に合わせた箱を、その物の子に作る
- **前に作ったシーンの当たり判定を見た目の子に移す**: 当たり判定が `CyberStage_Collision` に分かれていた古いシーン用。外形がぴったり同じ物の子に移す
- 当たり判定の箱はシーンでクリックしても選ばれない(見た目の物が選ばれる)。当たり判定だけ大きさを直したいときは、ヒエラルキーで `〜_Col` を選ぶ
- **ゲームへ書き出す**: 先にシーンを保存しておく。**原点の床は y=0 のままにする**(ゲームはそこをステージの高さの基準にする)
  書き出した後はゲームをビルドし直さなくてよい(起動し直してステージセレクトの「ステージ1」)
- 敵の進み方(フェーズ)は `2026_winter/data/Stage/PhaseFlow/PhaseStage005.csv` を手で直す

## 6. Unity MCP を使うとき

Unity を開いたまま Claude Code に頼むと、Unity MCP で直接シーンを調べたり直したりできる(新しい会話から)。
例:「CyberStage の 03_Plaza の建物を全部 2m 右へ」「今の注視点に壁走りの壁を置いて」
