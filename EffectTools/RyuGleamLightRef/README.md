# 忍者外伝4 リュウの閃華の弱(Gleam Form: Light Attack) 調査メモ (2026-11-25)

地上弱スキル(LB＋X)のエフェクトを作る前の下調べ。
動画: 【Ninja Gaiden 4】Ryu Hayabusa Moveset Showcase (YouTube 1QcPGY2155o) の 3:01〜3:05(181〜185秒)。
ブラウザで 0.1〜0.2 秒ずつ止めて見た(画像は保存していない。見たいときは上の時間を開く)。

## 技の形
- 入力は L2 を押しながら □□□ の3段。空中版(Air)もある。
- 1段の長さは 1 秒前後。どの段も「消える → 斬り抜ける → 出てくる」。

## 色と質感
- 体(分身)は**白〜うすい青(ラベンダー寄り)**。半透明で、縁が煙・風のようにちぎれる。
- 赤は**斬撃の直線と血だけ**。細く、長く、まっすぐ。
- 決めの瞬間(2・3段目)は画面ごと青く沈む・ぶれる。

## うちのゲームとの関係
- 今のスキルの分身 `data/Effect/Skill/GhostDash.efkefc` は、プレイヤーのポーズのメッシュ(`Ghost_Dodge_F_13.efkmodel`)を
  白〜うすい青の霊体にして回し、ちぎれるように消す作り。色も質感も閃華とほぼ同じ。
- 地上弱スキルはこの分身を土台にして、閃華の弱の「白い平たい残像」「赤い直線」「青白の風の帯」を足すと合う。

## 動き(11/26 見直し。線・エフェクトではなく体の動きだけ)
- 1段目(181.3〜182.3): しゃがんで構える(約0.1秒) → 体が霊体にほどける → **低く前へ突っ込み、敵の所で斬り上げながら抜ける**(約0.25秒) → 敵の向こうにしゃがんで着地。通り道に風が残る。
- 2段目(182.5〜183.4): 向こう側で一瞬ためて、**跳ね返るように、上から斜め下へ袈裟に斬り返して**元の側へ戻る(1段目の線と交差する) → しゃがんで着地。
- どちらも「1回の突進」で、分身が何体も出るわけではない。速いのは突進の0.2〜0.3秒だけで、構えと着地で間がある。
