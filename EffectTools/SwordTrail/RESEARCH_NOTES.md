# 剣の風切りの白い軌跡(NINJA GAIDEN 4 のヤクモ)の調査

2026-11-18。プレイヤーの攻撃にエフェクトを付ける前の調査。まだ何も作っていない。

  - `武器-鬼刃建御名方`(rFQ-mUOrbH0)1.767〜1.867秒: 振り上げの1振り → `ref/kijin_seq_1767-1867.jpg`、拡大 `ref/kijin_1800_zoom.jpg`
  - `基本アクション-飛燕`(gNHZxwa3LT0)1.60〜1.70秒: 回転斬り → `ref/hien_seq_160-170.jpg`
  - `基本アクション-崩撃`(vhfihHxZPa0): 鵺の型の赤い軌跡(今回の対象外)

## 見た目(コマ送りで分かったこと)
1. **振りの弧の全体に一度に出る**。刀を追いかけて伸びるのではなく、1コマ目でもう扇形が全部ある
   → 刀の先の位置を毎フレームつなぐリボン(トレイル)ではなく、**振りごとに弧の形の板(メッシュ)を出している**ように見える。
2. **中身は細い線の束**。白〜薄い灰色の髪の毛のような細い線が、弧に沿って何十本も並ぶ(刷毛で掃いた跡、風の筋)。
   線の長さはばらばらで、扇の端からはみ出す線もある。線の間はうっすら白いもや(少し透ける)。
3. **消え方は「広い扇 → 先の細い三日月」**:
   - 1コマ目: 広い扇(半透明の細い線の束)
   - 2コマ目: 扇が刀の進む側へ縮み、先のふちが太く白くなる。根元側の線は薄れる
   - 3コマ目: 先だけの細く明るい三日月＋もう1本うっすら。すぐ消える
   - **出てから消えるまで約3コマ = ゲームで約0.1秒(6F前後)**。とても短い。
4. **色は白〜灰色だけ**。光る(加算で白飛びする)感じは弱く、むしろ半透明の白(アルファブレンド寄り)。暗い背景でも白く光り過ぎない。
   赤は鵺の型(赤い型)のときで、ふつうの攻撃は白。
5. 回転斬り・連続で振る技は、**半径の違う弧が何枚も重なる**(飛燕 1.67〜1.70)。重なった所に白いもや・ゆがみ(空気が揺れるような感じ)が出る。
6. 血しぶき・火花は別のエフェクトとして重なる(斬った瞬間の当たりの光は別)。

## 作るときの方針の案(Effekseer)
- **形: 弧の板のメッシュ(扇形・円弧の帯)を振りごとに出す**。振りの向き・角度・半径は攻撃ごとに違うので、
  案A: 攻撃(ComboChain の行)ごとに回転・大きさを指定して1種類の弧を出す / 案B: 振りの種類(横・縦・斜め・回転)ごとに数種類作る。
  刀の先をつなぐリボン(Effekseer の Ribbon / Track を刀の先に付ける)は、刀より遅れて伸びるので NG4 の「一瞬で全体が出る」感じとは違う。
- **素材: 細い線の束のテクスチャを自作する**(knowledge.md の「形がらしさの核なら自作」)。
  横に長い画像に、長さ・太さ・濃さのばらばらな細い線を数十本。端は alpha 0。
- **消え方: 扇の根元側から削って、先だけ残す**。UV を流す(弧の後ろから前へ) or アルファの閾値(AlphaCutoff の FCurve。血の BloodHit で動いた)を上げる + 先のふちに明るい線。
- **長さは約6F**。ヒットストップやスローがあればそれに従う(EffectManager はタイムスケールに従う)。
- 色は白(少し青み)、アルファブレンド中心に、先のふちだけ少し加算。
- 回転斬りは半径を変えた弧を2〜3枚。

## 制作の記録
### 関門② シルエット(SwordSlash_v1、2026-11-18)
- 素材は `gen_slash_assets.ps1 -OutDir <版のフォルダ> -Suffix <接尾辞> -Cup <反り>`(テクスチャ `ST_Streaks/Edge/Haze`、弧のメッシュ `SlashArc`、人型 `ST_Dummy`)。BOM付きUTF-8で保存すること。
- 大きさ(1/20): 人型の高さ 9(=180cm)、弧は半径 2〜8(刃先まで約150cm)、角度 150°。横振りは高さ6、縦振りは高さ7で Z軸に90°、斜めは40°。弧は +Z(前)に出る。
- 今の版: メッシュ `SlashArc_b`(反り2.5。0.6 の `_a` より真後ろから見たときに幅が出る)、テクスチャ `_d`(線の束)/ `_e`(先のふち・もや)。
- 直したこと:
  - 扇の振り終わりの端が中心からの直線で終わり、縦の切れ目に見えた → 外側ほど先まで伸びる三日月の形(`Lead(v) = 0.5 + 0.45v`)にした。
  - Effekseer のカメラ: angleY=0 は人型の**正面**(敵の側)から見る。ゲームのカメラ(真後ろ)は **angleY=180**、戦闘中のカメラ(BattleSmoothCamera は60°回る)は **angleY=120**、高さはどちらも約18°。
- 分かったこと: 弧の面は前に伸びるので、**ゲームのカメラ(後ろ・横60°)からはどの振りも細い線に近い**。線の束が見えるのは面がカメラを向いたとき(NG4 の参考のコマもそう)。

### 関門③ 質感と色(SwordSlash_v2、2026-11-18)
- 決定: ゲームのカメラから細く見える件は**案A(再生時に弧の面をカメラへ傾ける)**。エディタでは横振りを X軸に -28°(面の向きをカメラへ約4割)傾けて確認した。真後ろの18°からでも帯として見えるが、まだ細め。ゲームでは傾ける割合を調整できるようにする。
- 2案(`Slash` = P、`Slash_D` = Q。どちらも横振り・-28°):
  - P(今の版): 線 `ST_Streaks_d`(70本)・不透明度255、もや120、先のふち(加算)170。外側の線がはっきり・先のふちが光る。
  - Q(控えめ): 線 `ST_Streaks_f`(140本・太さ0.6倍・濃さ0.8倍)・230、もや160、先のふち110。細かい線＋白いもやで、参考のコマの「空気を切る」感じに近い。
- 比較: `SwordSlash_v2/compare_gate3.png`(面を向けた / ゲームのカメラ × 暗い背景 / 灰色の背景)。灰色の背景(95,100,110)でもどちらも白く読める。

- 決定: **P(今の版)**。
### 関門④ 動き(SwordSlash_v3、2026-11-18)
- Q と斜め振りの見本を消した。縦振り(`Slash_V`)は非表示のまま(まだ動きを入れていない)。
- **アルファの閾値(AlphaCutoff)とアルファ画像(AlphaTexture)は、モデル＋標準のマテリアルでは効かなかった**(閾値0.95でも見た目が変わらない)。
- 代わりに **色の画像の UV を FCurve で刃先の側へ縮める**: `Wrap=Clamp`、`UV=FCurve`、Size.X = 1024/k、Start.X = 1024 − Size.X(k は見えている長さの割合。1 → 0.3)。画像の端はアルファ0なので、はみ出した所は消える。
  - Streaks: 寿命7F、Size.X 1024/1280/2048/3400(0/2/4/7F)、最後の3Fでフェード。
  - Edge: 寿命9F、Size.X 1024/1100/1700/2600(0/3/6/9F)、最後の4Fでフェード。
  - Haze: 寿命4F、最後の3Fでフェード。
  - 3つとも Y軸に 3°/F 回す(刃先の進む向き)。
- `capture_timeline` は最初、設定を変えても同じ絵が出た(閾値が効いていなかったため)。UV の FCurve は連続画像にも写る。
- 比較: `SwordSlash_v3/compare_gate4.png`(上が NG4 の 2Fごと、下が v3)。

### 関門⑤ 付加要素(SwordSlash_v4、2026-11-18)
- 縦振り `Slash_V`: 横振り `Slash`(動き入り)の複製を、Z軸に90°・Y軸に-25°(カメラ側へ少し向ける)。
- 回転斬り `Spin`(None、寿命20): 子に `Slash` の複製を3つ。`ArcA`(Y0°・倍率1.0)、`ArcB`(Y120°・0.85・高さ+0.4・2F遅れ)、`ArcC`(Y240°・1.12・高さ-0.3・4F遅れ)。どれも X軸に-12°。遅らせるのは `CommonValues.Generation.GenerationTimeOffset`。約12Fで一周して消える。
- 刃先の進む向きは +Y回転(弧の u=1 の側)。回転斬りの弧も +Y の順に並べた。
- 4方向とゲームのカメラ: `SwordSlash_v4/compare_gate5_4dir.png`(3F目)、回転斬りの連続画像 `shots/spin_seq_0-14.png`。真上・真下から人型が消えるのは、人型が Y軸固定のビルボードのため。

### 関門⑦ 書き出しとゲームへの組み込み(2026-11-18)
- `SwordSlash_game/` で確認用の人型などを外して書き出した: `data/Effect/Slash/SwordSlash.efk`(Slash のみ、原点・回転0)、`SwordSlashSpin.efk`(Spin のみ)。使う素材は `Texture/ST_Streaks_d.png`・`ST_Edge_e.png`・`ST_Haze_e.png`、`Model/SlashArc_b.efkmodel`。
- 向きは CSV で手で書く予定だったが、刀の先の実際の通り道から毎回計算する形にした(攻撃ごとに弧の真ん中が前とは限らず、横・縦・斜めの角度だけでは表せなかったため)。CSV は出すフレームと種類だけ。
- ハマったこと:
  - 刀のメッシュは拡大されたフレームの下にあり、メッシュの範囲だけで先を求めると手の位置になった → フレームの行列を掛ける。
  - 刀の行列は前のフレームのもの、モデルの行列は今のもので、向き直りの間に通り道が輪になった → 今の手のボーンから刀の先を計算する。
  - ワールドで覚えると向き直り・前進が混ざる → モデルの空間で覚える。
  - **DxLib(EffekseerForDXLib)で読んだエフェクトは Z が逆**。行列を渡すときに Z を -1 倍する。
  - 出すフレームは振りの速い区間の終わり。最初は刀の先を間違えた計測で決めていて、構えの途中で出ていた。
- 結果の画像: `game_shots/sheet_newframes_f1.png`(出た直後)・`_f4.png`(3F後)。確認用の線は 黄=刀の先の通り道、赤=刃先の向き、青=弧の真ん中、緑=面の向き、桃=今の刀の先。空中弱攻撃1だけ弧が少しずれる。

### 作り直し: 向きはそのまま(2026-11-18)
- 刀の先から向きを計算する版は、実際に遊ぶと「出ない」「変な向き」がほとんどだった(計算できないと出さない作り、向き直り中の誤差など)。
- 関門②の分かれ道で案B(カメラへ傾けない。細く見えることがある)を選び直し、**プレイヤーの前に水平でそのまま出す**形にした。CSV で出すフレームになったら必ず出る。傾けたい攻撃だけ `slashRoll`(度)で回す。
- `PlayerWeapon` に足した刀の先の計算は元に戻した。
- 撮影: `game_shots/v2_sheet_f1.png`(出た直後)・`v2_sheet_f4.png`(3F後)。全部の攻撃で出ている。

### 見た目に合わせた角度(2026-11-18)
- 向きを `slashYaw`(上を軸に前を回す)・`slashRoll`(前を軸に傾ける)・`slashSpin`(面の中で回す)の3つにした。roll だけでは弧の真ん中が横・後ろ寄りの振りを表せない。
- 値はゲーム中に計算せず、`tools/SwordSlashProbe/probe.exe` でアニメから前もって計算して CSV に書いた(`SLASH` の行)。大きさは18倍(刀の先まで約110〜160)。
- 撮影: `game_shots/v3_sheet_f1.png`・`v3_sheet_f4.png`。ほとんどの攻撃で三日月の先が刀の先の近くに来る。地上強2・切り上げ・空中弱1は少しずれる。

### 剣先からの軌跡に切り替え(2026-11-18)
- 弧の板を置く方式は、向きを計算しても CSV の角度で置いても、攻撃ごとに合わせる手間が大きかった。回転攻撃も出なかった(slashType を使っていなかった)。
- **刀身の根元と先を毎フレーム覚えて帯を描く方式**にした(`PlayerSwordTrail`)。推定が無いので向きはずれない。CSV は軌跡を伸ばす区間だけ。
- 見た目: 同じ画像(線の束・もや・先のふち)を帯に貼る。u は古い側0〜新しい側0.95(画像の三日月の形で、根元側は少し遅れる)、点は8Fで消える。最初は薄くて見えにくかったので、線の束を加算でも重ね、もやを足し、薄くなり方をゆっくりにした。
- 撮影: `game_shots/trail2_sheet_*.png`(3Fおき)、`trail_spin_2.png`(空中弱5を空中で)。
- NG4 との違い: NG4 は扇が一度に出るが、こちらは刀を追って伸びる(速い振りでは2〜3フレームで扇になる)。

## ゲーム側で気になること(作る前に決めること)
- 攻撃ごとに、刀がどの面をどの向きに振っているか(弧の向き・角度)をどう決めるか。
  - ComboChain01.csv に列を足して角度を手で書く / 当たり判定が出たフレームの刀の先の位置を数フレーム記録して弧を決める(自動)。
- 刀の先の位置は今は取っていない(`PlayerWeapon` は右手のボーンの行列 + ずらし で刀を描いているだけ)。自動にするなら刀の先の位置を返す関数が要る。
- 出すタイミング: 攻撃判定の開始(attackColStart)か、アニメのフレーム指定か。
